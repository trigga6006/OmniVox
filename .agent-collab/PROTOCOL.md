# Tandem Agent Protocol

1. Read STATUS.md, CLAIMS.md, and repo-local instructions before non-trivial work.
2. Claim a task or file scope before editing.
3. Do not edit files covered by another active claim without user approval.
4. Keep claims short-lived and release them when done.
5. Log meaningful changes, decisions, and verification commands.
6. Update STATUS.md before ending a turn.
7. Use HANDOFF.md when another agent should continue.
8. Prefer narrow, reversible edits over broad rewrites.
